# 星座神话
## 简介
这本书系统介绍了托勒密星座背后的神话故事，但是不止如此。 我认为本书的特点就是将词源学与神话故事与星座联系了起来，让我们知道了与星座有关的词根词缀和他们对应的拉丁、古希腊、梵语甚至古埃及语词源。

## 思考
作者是从字母起源的角度出发的，先简单的介绍了从最早的古印欧字母到希腊到拉丁再到如今的英语的进化历程。正是因为文明的流向如此，才会产生借词的现象。相对落后和新生的文明向古老的文明学习，因此将古老文明中已有的词语借过来并继续向后演化，因此出现了转写啊，词根词缀的变化啊什么的。yysy，星座背后的神话介绍的希腊神话如今大多已经是老生常谈，就算没认真看过神话但是故事八成也都听的七七八八了，但是这本书的词源学是特色，反而是这方面受益匪浅。
