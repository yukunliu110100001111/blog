# 《分成两半的子爵》

我们的子爵大人一上来就垫了,变成了两半,坏的一半被人救了回来,但是开始在家乡胡作非为了.尽管从道德意义上来说我认为这个人是一个坏人(他就是很纯粹的在干坏事),但是他也是一个清楚而明白的人. 完整的子爵看不清自己,而只有被炸开之后世界才变得清晰而明了,也许这个就是卡尔维诺所说的"追求不受社会摧残的完整人生"?  豆瓣热评里的那句"理解世界上每个人由于自我不完整而感到的痛苦，理解每一事物由于自身不完全而形成的缺陷"说的挺到位的, 一个普通的人对于自身的不完整和扭曲所感觉到的只有模糊的痛苦,只有将自己切开才能更好的理解这个世界. 切开的人尽管视野更加明晰,但是却因为不完整而趋于极端,变成了极为道德的人和极为邪恶的人,只有归于完整后才能重新得到一个既不好也不坏,普通而完整的人.
这三部曲的记述者"我"都是一个与主人公有一定关系但是不算亲密的人,在我们的口中记叙的故事都给整个故事附上了一股不确定而略有迷幻的色彩. 有点像是吟游诗人在叙述一个传奇的一生一样的感觉,也许这种听众氛围就是那种寓言故事感的来源.
