# 《蟫》

这本书有两点很有趣：首先是它的视角很有趣， 它用蟫（书虫）的视角描写了古书的流转，以及最重要的人与人之间的关系，这样我们的视角即是亲历者又是叙述者，带有着第三方的客观又似乎隔着人心的一道迷雾。他人叙述故事倒是常见，但是用蟫这个书虫的意向则一下子给这个书加了一点书香（是的，我看书虫吃书甚至还有一点点馋）。

然后是它的题材很有趣：它选用了文献学这个一个小众学科。整本书围绕着《慈云楼藏书志》/《郑堂读书记》展开，两本书如同桥将两批人隔着两百年联系了起来。它不像是那种解密游戏或者刑侦案件一样的关联性，更像是故人种下大树，而今人拾得叶片一样的小小的惊喜感。

整本书的伏笔相当到位（总共也不长的一本小说，说真的总共就小小的一本书里面居然还是两个故事），虽说初期看的算是有点云里雾里，但是后面看着看着就搞懂了来龙去脉，也就沉浸进入了书中，体悟到一丝感动了。整个书是一个平淡口的小说并且笼罩着一股朦胧感，叙事说话都是点到为止，透着一股古风（或者说国风？我不知道，我中文书看的确实不多），跟我之前看的小说都不太相同，算是换换口味吧。整本书可能古籍专业的人看过来会更有感触吧，豆瓣上的书评大多由有古籍专业背景的人士所留，我就没有这方面的怀念感加分了，但是这本书确实也还算有趣。
