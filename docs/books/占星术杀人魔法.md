# 占星术杀人魔法

这本书很符合我的期望。正如它被推荐的理由：它的核心诡计很是精彩，真的很精彩。

但是在内容的编排上，人物的塑造上，情节推进等等地方都不太尽如人意，我不知道岛田庄司是在模仿谁的写作方式，但是其中有大段的神秘环境描写。跳脱出主线的旅游情节和并不理想的侦探/华生的塑造让本书的节奏略显不融洽，怎么说呢，容易出戏。当然这些绕道的描写也可以说是缓和了本书的气氛，作为一个谋杀侦探小说如果没有调节气氛的环节是不行的，会让整体气氛过于压抑，因此我们的华生君和御手洗侦探的斗嘴倒是还算有趣。

这一切都只能说是有利有弊的小问题，简单的影响了点观感，但是作为一个推理小说来说，他的案件安排是严重瘸腿的。whodunit 中规中矩 howdunit精彩绝伦，whydunit真是拉完了，browtf，这个动机真的说得过去吗？御手洗君你在感动什么，你在尊重什么？高智商人群的惺惺相惜？cos 莫里亚蒂x福尔摩斯？ 我觉得这本书就是很典型的先有一个点子，然后展开成了一整本书。相当符合处女作的地位，有很大的进步空间啊。（
