# Overview：
这个笔记目前是纯AI生成的.

第二学期接着上学期的 program derivation 往下走。上学期解决的是"怎么从 postcondition 推出一个**正确**的程序"，这学期的重点变成了"怎么推出一个**高效**的程序"。目前一共三个主题：

1. **Monotonicity**：利用单调性，把二维的 O(M\*N) 降到 O(M+N)
2. **O(N) → O(log N)**：利用线性组合 + 矩阵，把线性递推降到对数
3. **Search by elimination**：一个通用的"排除法"搜索框架

套路还是上学期那一套（domain model → rewrite post → invariant → guard → vf → loop body），只是 domain model 和 invariant 的选法更讲究了。

> [!NOTE]
> 这学期 loop body 的推导写法和上学期有点不一样：
> 上学期是先写 (n, r := n+1, E).P0，然后解出 E（正着推）。
> 这学期很多题是直接从 P0 出发，用 domain model 把它变形，最后凑成"(某个赋值).P0"的样子，最后一步写 { WP }（反着推）。
> 上学期笔记里说 WP "被隐藏在后面了"，这学期它终于正式露面了：{ WP } 这一步的意思就是"P0 变形之后，刚好等于先做这个赋值、再满足 P0"。
> 两种写法本质一样，哪个顺手用哪个。

# Monotonicity
## 核心思想
这一部分的题目 postcondition 基本都长这样：
```
r = 〈⊕ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : h.(f.i).(g.j)〉
```
也就是对所有 (i, j) 对都算一次。直接两重循环就是 O(M\*N)。

但是如果 f 和 g 是有序的（单调的），我们只需要看一个"角"上的元素，就能一次性确定**一整行**或者**一整列**的结果，然后把这一行/列扔掉。每一步扔掉一行或一列，最多 M+N 步就结束，复杂度 O(M+N)。

```
          n →           N
   m   [*][ ][ ][ ][ ]          * = 角上的元素 h.(f.m).(g.n)
   ↓   [ ][ ][ ][ ][ ]          D.n = 第 m 行剩下的部分（向右）
       [ ][ ][ ][ ][ ]          E.m = 第 n 列剩下的部分（向下）
   M
```

> [!NOTE] 和上学期的区别
> 上学期遇到一个新函数（比如 Segment Sum 里的 D.n），我们会继续推它的 D.0 和 D.(n+1)，一层一层往下建 model。
> 这里**不推了**：D 和 E 我们只用单调性"看一眼角上的元素"来判断，能确定就确定，确定不了就写 ?。

## 通用模板
```
Pre: f[0..M), g[0..N) 有序
Post: r = 〈⊕ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : h.(f.i).(g.j)〉

Domain model
(0) C.m.n = 〈⊕ i, j : m ≤ i < M ∧ n ≤ j < N : h.(f.i).(g.j)〉 , 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
    // 注意 C.m.n 表示"还没处理的部分"，和上学期 C.n 表示"已经处理的部分"方向相反
(1) C.M.n = Id⊕ , 0 ≤ n ≤ N                    // i 的 range 为空 {empty range}
(2) C.m.N = Id⊕ , 0 ≤ m ≤ M                    // j 的 range 为空
(3) C.m.n = C.(m+1).n ⊕ D.n , 0 ≤ m < M ∧ 0 ≤ n ≤ N     // {split off i = m}：拿掉第 m 行
(4) C.m.n = C.m.(n+1) ⊕ E.m , 0 ≤ m ≤ M ∧ 0 ≤ n < N     // {split off j = n}：拿掉第 n 列
(5) D.n = 〈⊕ j : n ≤ j < N : h.(f.m).(g.j)〉              // 第 m 行剩下的部分
(6) E.m = 〈⊕ i : m ≤ i < M : h.(f.i).(g.n)〉              // 第 n 列剩下的部分
(7)~(10) 用单调性，按角上元素的情况讨论 D.n 和 E.m，能直接算出来就写出来，算不出来写 ?

Rewrite post
Post: r = C.0.0

Choose invariants
P0: r ⊕ C.m.n = C.0.0      // r = 已经处理掉的部分，C.m.n = 还没处理的部分，合起来就是答案
P1: 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
// 这个形状和上学期 Recursion 里的 r ⊕ f.n = f.N 是一样的，都是 tail invariant

Establish invariants
r, m, n := Id⊕, 0, 0      // 一开始什么都没处理

Guard
m ≠ M ∧ n ≠ N

vf
(M-m) + (N-n)

Loop body（以拿掉一行为例）
P0
= { defn. }
r ⊕ C.m.n = C.0.0
= { (3) }
r ⊕ C.(m+1).n ⊕ D.n = C.0.0
= { case xxx, 这时 D.n 已知等于 d }
r ⊕ d ⊕ C.(m+1).n = C.0.0
= { WP }
(r, m := r ⊕ d, m+1).P0
// 拿掉一列同理，用 (4)，得到 (r, n := r ⊕ e, n+1).P0
```

Guard 是这样推出来的：
```
P0 ∧ m = M
⇒ { Leibniz }
r ⊕ C.M.n = C.0.0
= { (1) }
r ⊕ Id⊕ = C.0.0
= { Id⊕ }
r = C.0.0
// n = N 同理

所以 P0 ∧ (m = M ∨ n = N) ⇒ Post，取反就是 guard：m ≠ M ∧ n ≠ N
// 只要有一边走完了，剩下的矩形就是空的，所以 guard 是 ∧ 不是 ∨
```

> [!NOTE] 关于 vf
> PDF 里有几章写的是 (M-m) ↓ (N-n)，还有几章留作 exercise。
> 严格来说 ↓ 不行：每一轮只有 m 或 n 中的一个前进。比如 M-m = 5, N-n = 2 的时候做 m := m+1，取 min 之后还是 2，没有严格下降。
> 用 (M-m) + (N-n) 就没问题：每一轮一定减 1，由 P1 有下界 0。这也正好对应复杂度 O(M+N)。
> 考试的时候建议写 +，或者先问一下老师接受哪种。

## D 和 E 的 "?" 表，以及怎么选角
这一块是整个 Monotonicity 的灵魂。拿 Pairs whose sum exceeds 37 举例（f 升序，g 降序），看角上的 f.m + g.n：
- 第 m 行剩下的是 f.m + g.j (j ≥ n)。g 是降序的，所以 f.m + g.n 是**这一行里最大的**
- 第 n 列剩下的是 f.i + g.n (i ≥ m)。f 是升序的，所以 f.m + g.n 是**这一列里最小的**

所以：

| 情况 | D.n（第 m 行） | E.m（第 n 列） | 动作 |
| --- | --- | --- | --- |
| f.m + g.n ≤ 37 | 0（行里最大的都 ≤ 37） | ? | 扔掉第 m 行：m := m+1 |
| f.m + g.n > 37 | ? | M-m（列里最小的都 > 37） | 扔掉第 n 列：r, n := r+M-m, n+1 |

> [!NOTE] 选角的原则（自己总结的）
> 角上的元素必须同时是"所在行剩余部分的最大值"和"所在列剩余部分的最小值"（或者反过来）。这样不管比较结果是大是小，总有一边（行或列）能被整个确定下来。
> 只要**每一种情况下 D 和 E 至少有一个不是 ?**，这个 domain model 就是 adequate（够用）的，就能写出程序。
> - 行列都升序的二维数组：角选右上（或左下）
> - f 升序、g 降序，算 f + g：角选两个数组的开头
> - 选错了角（比如选到了整个矩形的最小值），就会出现某种情况下 D、E 都是 ?，程序写不下去

## Pairs whose sum exceeds 37
给定 f[0..M) 升序 (≤)，g[0..N) 降序 (≥)，数一下有多少对 f.i + g.j > 37。

```
Post: r = 〈+ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : h.(f.i).(g.j)〉

Domain model
(0) h.x.y = 1 ⇐ x+y > 37
(1) h.x.y = 0 ⇐ x+y ≤ 37
(2) C.m.n = 〈+ i, j : m ≤ i < M ∧ n ≤ j < N : h.(f.i).(g.j)〉 , 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
(3) C.M.n = 0 , 0 ≤ n ≤ N
(4) C.m.N = 0 , 0 ≤ m ≤ M

C.m.n
= { (2) }
〈+ i, j : m ≤ i < M ∧ n ≤ j < N : h.(f.i).(g.j)〉
= { split off i = m term }
〈+ i, j : m+1 ≤ i < M ∧ n ≤ j < N : h.(f.i).(g.j)〉 + 〈+ j : n ≤ j < N : h.(f.m).(g.j)〉
= { (2) (7) }
C.(m+1).n + D.n

(5) C.m.n = C.(m+1).n + D.n , 0 ≤ m < M ∧ 0 ≤ n ≤ N
(6) C.m.n = C.m.(n+1) + E.m , 0 ≤ m ≤ M ∧ 0 ≤ n < N      // split off j = n，同理
(7) D.n = 〈+ j : n ≤ j < N : h.(f.m).(g.j)〉 , 0 ≤ n ≤ N
(8) E.m = 〈+ i : m ≤ i < M : h.(f.i).(g.n)〉 , 0 ≤ m ≤ M
(9)  D.n = ?   ⇐ f.m + g.n > 37
(10) D.n = 0   ⇐ f.m + g.n ≤ 37
(11) E.m = M-m ⇐ f.m + g.n > 37
(12) E.m = ?   ⇐ f.m + g.n ≤ 37

Post: r = C.0.0
P0: r + C.m.n = C.0.0
P1: 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
Establish: r, m, n := 0, 0, 0
Guard: m ≠ M ∧ n ≠ N
vf: (M-m) + (N-n)

Loop body:
P0
= { defn. }
r + C.m.n = C.0.0
= { (5) }
r + C.(m+1).n + D.n = C.0.0
= { case f.m + g.n ≤ 37 (10) }
r + C.(m+1).n + 0 = C.0.0
= { Id+ }
r + C.(m+1).n = C.0.0
= { WP }
(m := m+1).P0

P0
= { defn. }
r + C.m.n = C.0.0
= { (6) }
r + C.m.(n+1) + E.m = C.0.0
= { case f.m + g.n > 37 (11) }
r + C.m.(n+1) + M-m = C.0.0
= { WP }
(r, n := r+M-m, n+1).P0

最终程序：
r, m, n := 0, 0, 0
;do m ≠ M ∧ n ≠ N →
	if f.m + g.n ≤ 37 → m := m+1
	[] f.m + g.n > 37 → r, n := r+M-m, n+1
	fi
od
// O(M+N)
```

## Different domain models（同一题的四种模型）
同样是 pairs > 37，C.m.n 的 range 其实有四种写法（i 和 j 各自可以是"从 m 到尾"或者"从头到 m"）。PDF 把四种都列了一遍，只看 (9)~(12) 能不能覆盖所有情况：

| 模型 | i 的范围 | j 的范围 | 看的角 | > 37 时 | ≤ 37 时 | adequate? |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | m ≤ i < M | n ≤ j < N | f.m + g.n | D = ?, E = M-m | D = 0, E = ? | ✓ |
| 2 | m ≤ i < M | 0 ≤ j < n | f.m + g.(n-1) | D = n, E = M-m | D = ?, E = ? | ✗ |
| 3 | 0 ≤ i < m | 0 ≤ j < n | f.(m-1) + g.(n-1) | D = n, E = ? | D = ?, E = 0 | ✓ |
| 4 | 0 ≤ i < m | n ≤ j < N | f.(m-1) + g.n | D = ?, E = ? | D = 0, E = 0 | ✗ |

用上面选角的原则就很好理解：
- 模型 2 的角 f.m + g.(n-1) 是 f 剩下的最小值 + g 剩下的最小值（g 降序，j < n 里 g.(n-1) 最小），也就是**整个矩形的最小值**。它 > 37 的时候整个矩形都确定了，但 ≤ 37 的时候什么都不知道
- 模型 4 正好相反，角是整个矩形的最大值
- 模型 1 和模型 3 的角都是"行里最大、列里最小"的那种，所以是 adequate 的

模型 3 也能写出程序，就是从另一个角往回走（自己写的，和暴力解对拍过）：
```
r, m, n := 0, M, N
;do m ≠ 0 ∧ n ≠ 0 →
	if f.(m-1) + g.(n-1) > 37 → r, m := r+n, m-1
	[] f.(m-1) + g.(n-1) ≤ 37 → n := n-1
	fi
od
```

## The coincidence count
给定 f[0..M), g[0..N) 都是**严格**递增 (<)，数一下有多少对 f.i = g.j。
```
Post: r = 〈+ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : h.(f.i).(g.j)〉
h.x.y = 1 ⇐ x = y
h.x.y = 0 ⇐ x ≠ y

Domain model 和 pairs > 37 完全一样（C.m.n、D.n、E.m 的定义都不变），只有 D 和 E 的表不一样：
(9)  D.n = 0 ⇐ f.m < g.n       // 第 m 行剩下的 g.j 都 ≥ g.n > f.m
(10) D.n = 1 ⇐ f.m = g.n       // 严格递增，所以这一行只有 g.n 这一个能等于 f.m
(11) D.n = ? ⇐ f.m > g.n
(12) E.m = ? ⇐ f.m < g.n
(13) E.m = 1 ⇐ f.m = g.n
(14) E.m = 0 ⇐ f.m > g.n

最终程序：
r, m, n := 0, 0, 0
;do m ≠ M ∧ n ≠ N →
	if f.m < g.n → m := m+1
	[] f.m = g.n → r, m := r+1, m+1
	[] f.m = g.n → r, n := r+1, n+1
	[] f.m > g.n → n := n+1
	fi
od
// O(M+N)
```
> [!NOTE]
> 这里有两个分支的 guard 都是 f.m = g.n。Guarded Command Language 允许 guard 重叠（nondeterminism），两个分支都能保持 P0，执行哪个都对。实际写代码的时候随便留一个就行。
> 另外注意题目要求是**严格**递增，D.n = 1 这一步依赖这个条件；如果是 ≤ 的话一行里可能有好几个相等的值。

## The minimum distance
给定 f[0..M), g[0..N) 都是升序 (≤)，求 〈↓ i, j : ... : |f.i - g.j|〉。

这题的 ⊕ 换成了 ↓，h 也不再是 0/1 函数了，但模板完全一样。
```
Post: r = 〈↓ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : |f.i - g.j|〉

(0) C.m.n = 〈↓ i, j : m ≤ i < M ∧ n ≤ j < N : |f.i - g.j|〉
(1) C.M.n = Id↓              // Id↓ 就是 +∞
(2) C.m.N = Id↓
(3) C.m.n = C.(m+1).n ↓ D.n
(4) C.m.n = C.m.(n+1) ↓ E.m
(5) D.n = 〈↓ j : n ≤ j < N : |f.m - g.j|〉
(6) E.m = 〈↓ i : m ≤ i < M : |f.i - g.n|〉
(7)  D.n = g.n - f.m ⇐ f.m ≤ g.n     // f.m ≤ g.n ≤ g.j，所以 |f.m - g.j| = g.j - f.m，在 j = n 时最小
(8)  D.n = ?         ⇐ f.m > g.n
(9)  E.m = ?         ⇐ f.m ≤ g.n
(10) E.m = f.m - g.n ⇐ f.m > g.n     // 对称

P0: r ↓ C.m.n = C.0.0
Establish: r, m, n := Id↓, 0, 0

最终程序：
r, m, n := Id↓, 0, 0
;do m ≠ M ∧ n ≠ N →
	if f.m ≤ g.n → r, m := r ↓ (g.n - f.m), m+1
	[] f.m > g.n → r, n := r ↓ (f.m - g.n), n+1
	fi
od
// O(M+N)
```

## How many values at most equal to X
给定二维数组 f[0..M-1, 0..N-1]，**两个下标方向都升序**，数一下有多少个值 ≤ X。

这题角要选**右上角**：第 m 行剩下的是 j < n 的部分，f.m.(n-1) 是这一行剩下的最大值；第 n-1 列剩下的是 i ≥ m 的部分，f.m.(n-1) 是这一列剩下的最小值。
```
Post: r = 〈+ i, j : 0 ≤ i < M ∧ 0 ≤ j < N : g.(f.i.j)〉
g.α = 1 ⇐ α ≤ X
g.α = 0 ⇐ α > X

(2) C.m.n = 〈+ i, j : m ≤ i < M ∧ 0 ≤ j < n : g.(f.i.j)〉 , 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
    // 注意 j 的范围是 0 ≤ j < n，n 是从 N 往下走的
(3) C.M.n = 0
(4) C.m.0 = 0
(5) C.m.n = C.(m+1).n + D.n          // split off i = m
(6) C.m.n = C.m.(n-1) + E.m          // split off j = n-1
(7) D.n = 〈+ j : 0 ≤ j < n : g.(f.m.j)〉
(8) E.m = 〈+ i : m ≤ i < M : g.(f.i.(n-1))〉
(9)  D.n = ? ⇐ X < f.m.(n-1)
(10) D.n = n ⇐ f.m.(n-1) ≤ X        // 行里最大的都 ≤ X，整行 n 个都算
(11) E.m = 0 ⇐ X < f.m.(n-1)        // 列里最小的都 > X，整列都不算
(12) E.m = ? ⇐ f.m.(n-1) ≤ X

Post: r = C.0.N
P0: r + C.m.n = C.0.N
P1: 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
Establish: r, m, n := 0, 0, N
Guard: m ≠ M ∧ n ≠ 0                 // P0 ∧ (m = M ∨ n = 0) ⇒ Post，取反
vf: (M-m) + n

最终程序：
r, m, n := 0, 0, N
;do m ≠ M ∧ n ≠ 0 →
	if f.m.(n-1) ≤ X → r, m := r+n, m+1
	[] X < f.m.(n-1) → n := n-1
	fi
od
// O(M+N)
```

## Head/Tail sum
给定 f[0..N) of N+（**正整数**），数一下有多少对前缀和 = 后缀和。
```
Post: r = 〈+ i, j : 0 ≤ i ≤ N ∧ 0 ≤ j ≤ N : g.(H.i).(T.j)〉

Domain model
(0) g.x.y = 1 ⇐ x = y
(1) g.x.y = 0 ⇐ x ≠ y
(2) H.n = 〈+ j : 0 ≤ j < n : f.j〉 , 0 ≤ n ≤ N          // 前缀和 head sum
(3) T.n = 〈+ j : n ≤ j < N : f.j〉 , 0 ≤ n ≤ N          // 后缀和 tail sum
(4) H.0 = 0
(5) H.(n+1) = H.n + f.n
(6) H.n < H.(n+1)            // 因为 f 是正数，所以严格递增
(7) T.N = 0
(8) T.(n-1) = f.(n-1) + T.n
(9) T.n < T.(n-1)            // 严格递减
(10) H.N = T.0               // 都是整个数组的和

(11) C.m.n = 〈+ i, j : m ≤ i ≤ N ∧ 0 ≤ j ≤ n : g.(H.i).(T.j)〉
(12) C.N.n = 1               // 注意不是 0！H.N = T.0，j = 0 那一项一定相等
(13) C.m.0 = 1               // 同理
(14) C.m.n = C.(m+1).n + D.n
(15) C.m.n = C.m.(n-1) + E.m
(16) D.n = 〈+ j : 0 ≤ j ≤ n : g.(H.m).(T.j)〉
(17) E.m = 〈+ i : m ≤ i ≤ N : g.(H.i).(T.n)〉
(18) D.n = 0 ⇐ H.m < T.n
(19) D.n = 1 ⇐ H.m = T.n
(20) D.n = ? ⇐ H.m > T.n
(21) E.m = ? ⇐ H.m < T.n
(22) E.m = 1 ⇐ H.m = T.n
(23) E.m = 0 ⇐ H.m > T.n
```
为什么 j 的范围要取 0 ≤ j ≤ n（从后往前）？因为 H 递增、T 递减，H.i - T.j 对 i 和 j **都是递增的**。要让角 (m, n) 是"行里最大、列里最小"，行就得取 j ≤ n，列取 i ≥ m。

Guard 这里有个小坑：
```
r + C.m.n = C.0.N ∧ m = N
⇒ { Leibniz }
r + C.N.n = C.0.N
= { (12) }
r + 1 = C.0.N
// n = 0 同理也是 r + 1 = C.0.N
```
所以循环结束的时候只有 r + 1 = C.0.N，**最后要补一个 r := r+1**。

```
P0: r + C.m.n = C.0.N
P1: 0 ≤ m ≤ N ∧ 0 ≤ n ≤ N
Establish: r, m, n := 0, 0, N
Guard: m ≠ N ∧ n ≠ 0
vf: (N-m) + n

第一版程序：
r, m, n := 0, 0, N
;do m ≠ N ∧ n ≠ 0 →
	if H.m < T.n → m := m+1
	[] H.m = T.n → r, m := r+1, m+1
	[] H.m = T.n → r, n := r+1, n-1
	[] H.m > T.n → n := n-1
	fi
od
{ r+1 = C.0.N }
;r := r+1
{ r = C.0.N }
```

但是每次判断 guard 都要算一遍 H.m 和 T.n，这又变慢了。解决办法是**强化不变量**：
```
P2: x = H.m ∧ y = T.n

Establish:
(r, m, n, x, y := 0, 0, N, U, U').P2
= { text sub. }
U = H.0 ∧ U' = T.N
= { (4) (7) }
U = 0 ∧ U' = 0

m+1 的时候：
(m, x, y := m+1, U, U').P2
= { text sub. }
U = H.(m+1) ∧ U' = T.n
= { (5) }
U = H.m + f.m ∧ U' = T.n
= { P2 }
U = x + f.m ∧ U' = y

n-1 的时候：
(n, x, y := n-1, U, U').P2
= { text sub. }
U = H.m ∧ U' = T.(n-1)
= { (8) }
U = H.m ∧ U' = f.(n-1) + T.n
= { P2 }
U = x ∧ U' = f.(n-1) + y

最终程序：
r, m, n, x, y := 0, 0, N, 0, 0
;do m ≠ N ∧ n ≠ 0 →
	if x < y → m, x := m+1, x + f.m
	[] x = y → r, m, x := r+1, m+1, x + f.m
	[] x = y → r, n, y := r+1, n-1, f.(n-1) + y
	[] x > y → n, y := n-1, f.(n-1) + y
	fi
od
;r := r+1
// O(N)
```

> [!NOTE] 强化不变量来去掉重复计算
> 程序里如果出现了一个计算很贵的表达式（H.m、T.n、D.a.b、f.n ……），就把它放进不变量里，用一个变量记着，每次赋值的时候顺手更新。
> 推导方式都一样：(赋值, x := ..., U).P2 → { text sub. } → 用 domain model 展开 → { P2 } 换成变量。
> 这个技巧这学期反复出现：Head/Tail 的 x, y，Starting pit 的 d，Fibolucci 的 a, b，还有 Σ A^(N-i)·B^i 那题的 s。

## Decomposition in the sum of two squares
给定 N : nat，数一下 N 能写成多少种 i² + j²（0 ≤ i ≤ j）。

这题的问题是 range **没有上界**。解决办法：先找一个 y 使 y² ≥ N，那么 j > y 的部分都不可能等于 N，可以扔掉。
```
Post: r = 〈+ i, j : 0 ≤ i ≤ j : g.i.j〉
(0) g.x.y = 1 ⇐ x² + y² = N
(1) g.x.y = 0 ⇐ x² + y² ≠ N
(2) C.0 = 〈+ i, j : 0 ≤ i ≤ j : g.i.j〉

C.0
= { (2) }
〈+ i, j : 0 ≤ i ≤ j : g.i.j〉
= { algebra }
〈+ i, j : 0 ≤ i ≤ j ≤ y : g.i.j〉 + 〈+ i, j : 0 ≤ i ≤ j ∧ j > y : g.i.j〉
= { 假设 y² ≥ N，那么 j > y 时 i² + j² > N，第二项为 0 }
〈+ i, j : 0 ≤ i ≤ j ≤ y : g.i.j〉
= { (3) }
D.0.y

(3) D.x.y = 〈+ i, j : x ≤ i ≤ j ≤ y : g.i.j〉
(4) y² ≥ N ⇒ D.0.y = C.0
(5) x > y ⇒ D.x.y = 0                     // empty range
(6) D.x.y = D.(x+1).y + E.x.y             // split off i = x
(7) D.x.y = D.x.(y-1) + F.x.y             // split off j = y
(8) E.x.y = 〈+ j : x ≤ j ≤ y : g.x.j〉     // 第 x 行
(9) F.x.y = 〈+ i : x ≤ i ≤ y : g.i.y〉     // 第 y 列
(10) E.x.y = 0 ⇐ x² + y² < N     // 行里最大的是 x² + y²
(11) E.x.y = 1 ⇐ x² + y² = N
(12) E.x.y = ? ⇐ x² + y² > N
(13) F.x.y = ? ⇐ x² + y² < N
(14) F.x.y = 1 ⇐ x² + y² = N
(15) F.x.y = 0 ⇐ x² + y² > N     // 列里最小的是 x² + y²（PDF 这里写成了 E.x.y，应该是 F.x.y）

Post: r = C.0
P0: r + D.x.y = C.0
P1: 0 ≤ x

Establish（这次需要一个小循环来找 y）：
r, x, y := 0, 0, 0
;do y² < N → y := y+1 od

Guard:
r + D.x.y = C.0 ∧ x > y
⇒ { (5) }
r + 0 = C.0
所以 guard 取 x ≤ y

最终程序：
r, x, y := 0, 0, 0
;do y² < N → y := y+1 od
;do x ≤ y →
	if x² + y² < N → x := x+1
	[] x² + y² = N → r, x := r+1, x+1
	[] x² + y² = N → r, y := r+1, y-1
	[] x² + y² > N → y := y-1
	fi
od
```
> [!NOTE]
> 这题有两个新东西：
> 1. establish invariant 不一定是一条赋值语句，也可以是一个循环（先把 y 推到上界）
> 2. guard 不是 "m ≠ M ∧ n ≠ N" 那种形状，而是直接由 (5) 推出来的 x ≤ y

## Slope Search
给定二维数组 f[0..M, 0..N]（注意是闭区间），两个方向都升序，**已知 X 一定在里面**，找到它的位置。

这是 Monotonicity 的**搜索版**：不再是数数，而是找一个位置，所以 ⊕ 变成了 ∨，C.m.n 变成一个布尔值，意思是"X 还在剩下的这个矩形里"。
```
Pre: 〈∃ i, j : 0 ≤ i ≤ M ∧ 0 ≤ j ≤ N : f.i.j = X〉
Post: 0 ≤ a ≤ M ∧ 0 ≤ b ≤ N ∧ f.a.b = X

Domain model
(0) C.m.n ≡ 〈∃ i, j : m ≤ i ≤ M ∧ 0 ≤ j ≤ n : f.i.j = X〉 , 0 ≤ m ≤ M ∧ 0 ≤ n ≤ N
(1) C.0.N ≡ true                    // 就是 Pre
(2) C.m.n ≡ C.(m+1).n ∨ D.n         // split off i = m
(3) D.n ≡ 〈∃ j : 0 ≤ j ≤ n : f.m.j = X〉           // 第 m 行，j ≤ n
(4) C.m.n ≡ C.m.(n-1) ∨ E.m         // split off j = n
(5) E.m ≡ 〈∃ i : m ≤ i ≤ M : f.i.n = X〉           // 第 n 列，i ≥ m
// 角 f.m.n 是第 m 行剩下部分的最大值，也是第 n 列剩下部分的最小值
(6)  D.n ≡ false ⇐ f.m.n < X
(7)  D.n ≡ true  ⇐ f.m.n = X
(8)  D.n ≡ ?     ⇐ f.m.n > X
(9)  E.m ≡ ?     ⇐ f.m.n < X
(10) E.m ≡ true  ⇐ f.m.n = X
(11) E.m ≡ false ⇐ f.m.n > X

Invariants
P0: C.a.b                       // X 还在剩下的矩形里
P1: 0 ≤ a ≤ M ∧ 0 ≤ b ≤ N
Establish: a, b := 0, N         // 从右上角开始
Guard: f.a.b ≠ X                // post 直接就是 f.a.b = X，和 linear search 一样
vf: (M-a) + b                   // PDF 留作 exercise

Loop body:
P0
= { defn. }
C.a.b
= { (2) }
C.(a+1).b ∨ D.b
= { case f.a.b < X (6) }
C.(a+1).b ∨ false
= { Id∨ }                        // Id∨ = false
C.(a+1).b
= { WP }
(a := a+1).P0

f.a.b > X 的时候同理用 (4) (11) 得到 (b := b-1).P0
f.a.b = X 的情况被 guard 挡住了，不用考虑

最终程序：
a, b := 0, N
;do f.a.b ≠ X →
	if f.a.b < X → a := a+1
	[] f.a.b > X → b := b-1
	fi
od
// O(M+N)
```
> [!NOTE]
> 每一步都排除掉一行或者一列——这其实就是 Search by elimination 的思想，后面会正式讲。

## Fast Exponentiation
先看最普通的写法，求 r = X^N：
```
Post': r = X^n ∧ n = N
P0: r = X^n
P1: 0 ≤ n ≤ N
Establish: n, r := 0, 1
Guard: n ≠ N
vf: N - n

(n, r := n+1, E).P0
= { text substitution }
E = X^(n+1)
= { algebra }
E = X * X^n
= { P0 }
E = X * r

n, r := 0, 1
;do n ≠ N →
	n, r := n+1, X * r
od
// O(N)
```

**Key insight**：
```
X^n = (X*X)^(n div 2)   ⇐ even.n
X^n = X * X^(n-1)       ⇐ odd.n
```
偶数的时候可以把底数平方、指数减半。但是上面的 invariant r = X^n 是从 0 往上数的，没地方用这个性质。所以换一个 **tail invariant**：
```
P0: r * y^n = X^N            // r = 已经结算的部分，y^n = 还剩下没算的部分
P1: 0 ≤ n ≤ N
Establish: n, r, y := N, 1, X

Guard:
r * y^n = X^N ∧ n = 0
⇒ { Leibniz }
r * y^0 = X^N
= { algebra }
r = X^N
所以 guard 取 n ≠ 0
vf: n

Loop body:
P0
= { defn. }
r * y^n = X^N
= { case even.n }
r * (y*y)^(n div 2) = X^N
= { WP }
(n, y := n div 2, y*y).P0

P0
= { defn. }
r * y^n = X^N
= { case odd.n }
r * y * y^(n-1) = X^N
= { WP }
(n, r := n-1, r*y).P0

最终程序：
n, r, y := N, 1, X
;do n ≠ 0 →
	if even.n → n, y := n div 2, y*y
	[] odd.n → n, r := n-1, r*y
	fi
od
{ r = X^N }
// O(log N)：odd 之后下一轮一定是 even，所以最多两步 n 就减半一次
```

> [!NOTE] head invariant vs tail invariant
> head invariant（r = X^n）：r 记的是"已经算好的前 n 步"，n 从 0 往上数到 N，只能一步一步加。
> tail invariant（r \* y^n = X^N）：r 记的是"已经结算的部分"，y^n 是"还剩下的部分"，n 从 N 往下降到 0。剩下的部分可以变形（底数平方、指数减半），所以能跳着走。
> 上学期 Recursion 里的 r ⊕ f.n = f.N 和 α\*fib.n + β\*fib.(n+1) = fib.N 也都是 tail invariant 的形状。
> 想要 O(log N)，关键就是找到一个能让"剩下的部分"减半的恒等式。

## 线性组合 → 矩阵 → 快速幂
如果 loop body 里每个变量的新值都是这些变量的**线性组合**，那就可以把它写成矩阵乘法 v := A \* v，于是 v_N = A^N \* v_0。矩阵的幂和数的幂一样可以"平方 + 减半"，所以套用快速幂就是 O(log N)。

| Step | 做什么 |
| --- | --- |
| 1. 先写 O(N) 版本 | head invariant，比如 x = f.n ∧ y = f.(n+1)，n 从 0 到 N |
| 2. 观察 loop body | 每个变量的新值是不是这些变量的线性组合（有常数项要先处理掉，见后面） |
| 3. 改写成矩阵 | v := A \* v，于是 post 变成 v = A^N \* v0 |
| 4. 换成 tail invariant | P0: A^N \* v0 = D^n \* v（D 是矩阵变量，v 是向量变量） |
| 5. Establish | n, D, v := N, A, v0 |
| 6. Guard / vf | n ≠ 0 / n |
| 7. Loop body | even.n → n, D := n div 2, D\*D；odd.n → n, v := n-1, D\*v |
| 8. 去掉矩阵 | 我们的语言没有矩阵，2x2 的矩阵拆成 a, b, c, d 四个变量 |

和快速幂一一对应：矩阵 D 对应 y，向量 v 对应 r。odd 的时候是把 D 乘到 v 上去（因为 D^n \* v = D^(n-1) \* (D \* v)），对应快速幂里的 r := r\*y。

去掉矩阵用的两个公式：

$$
\begin{pmatrix}a & b\\ c & d\end{pmatrix}^2 = \begin{pmatrix}a a+b c & (a+d) b\\ (a+d) c & b c+d d\end{pmatrix}
\qquad
\begin{pmatrix}a & b\\ c & d\end{pmatrix}\begin{pmatrix}x\\ y\end{pmatrix} = \begin{pmatrix}a x+b y\\ c x+d y\end{pmatrix}
$$

```
D := D*D   变成   a, b, c, d := a*a+b*c, (a+d)*b, (a+d)*c, b*c+d*d
v := D*v   变成   x, y := a*x + b*y, c*x + d*y
```

## Fast Fibonacci
```
(0) f.0 = 0
(1) f.1 = 1
(2) f.(n+2) = f.n + f.(n+1) , 0 ≤ n

先写 O(N) 版本：
P0: x = f.n ∧ y = f.(n+1)       // 只记 f.n 不够，强化成同时记 f.(n+1)
P1: 0 ≤ n ≤ N
Establish: n, x, y := 0, 0, 1
Guard: n ≠ N
vf: N - n

(n, x, y := n+1, E, E').P0
= { text substitution }
E = f.(n+1) ∧ E' = f.(n+2)
= { (2) }
E = f.(n+1) ∧ E' = f.n + f.(n+1)
= { P0 }
E = y ∧ E' = x + y

n, x, y := 0, 0, 1
;do n ≠ N →
	n, x, y := n+1, y, x+y
od
{ x = f.N ∧ y = f.(N+1) }
// O(N)
```
loop body 里 x, y 的新值都是 x, y 的线性组合，写成矩阵：

$$
\begin{pmatrix}x\\ y\end{pmatrix} := \begin{pmatrix}0 & 1\\ 1 & 1\end{pmatrix}\begin{pmatrix}x\\ y\end{pmatrix}
\qquad\Rightarrow\qquad
\begin{pmatrix}f.N\\ f.(N+1)\end{pmatrix} = \begin{pmatrix}0 & 1\\ 1 & 1\end{pmatrix}^N\begin{pmatrix}0\\ 1\end{pmatrix}
$$

换成 tail invariant：

$$
P0:\quad \begin{pmatrix}0 & 1\\ 1 & 1\end{pmatrix}^N\begin{pmatrix}0\\ 1\end{pmatrix} = A^n\begin{pmatrix}x\\ y\end{pmatrix}
$$

```
Establish: n, x, y, A := N, 0, 1, [[0,1],[1,1]]
Guard: n ≠ 0
vf: n
Loop body:
	even.n → n, A := n div 2, A*A
	odd.n  → n, (x,y) := n-1, A*(x,y)

去掉矩阵之后的最终程序：
n, x, y, a, b, c, d := N, 0, 1, 0, 1, 1, 1
;do n ≠ 0 →
	if even.n → n, a, b, c, d := n div 2, a*a+b*c, (a+d)*b, (a+d)*c, b*c+d*d
	[] odd.n → n, x, y := n-1, a*x + b*y, c*x + d*y
	fi
od
{ x = f.N }
// O(log N)，没有任何矩阵运算
```

## Another efficiency gain exploiting linear combinations
给定常数 A, B, N（0 ≤ N），求
```
Post: r = 〈+ i : 0 ≤ i ≤ N : A^(N-i) * B^i〉

Post': r = C.n ∧ n = N
(0) C.n = 〈+ i : 0 ≤ i ≤ n : A^(n-i) * B^i〉 , 0 ≤ n ≤ N
(1) C.0 = 1                    // 1-point，A^0 * B^0

C.(n+1)
= { (0) }
〈+ i : 0 ≤ i ≤ n+1 : A^(n+1-i) * B^i〉
= { split off i = n+1 term }
〈+ i : 0 ≤ i ≤ n : A^(n+1-i) * B^i〉 + A^0 * B^(n+1)
= { algebra }
〈+ i : 0 ≤ i ≤ n : A * A^(n-i) * B^i〉 + B^(n+1)
= { */+ }                       // 乘法对加法分配，把 A 提出来
A * 〈+ i : 0 ≤ i ≤ n : A^(n-i) * B^i〉 + B^(n+1)
= { (0) }
A * C.n + B^(n+1)

(2) C.(n+1) = A * C.n + B^(n+1) , 0 ≤ n < N
```
C.(n+1) 里需要 B^(n+1)，所以强化不变量，用 s 记着它：
```
P0: r = C.n ∧ s = B^(n+1)
P1: 0 ≤ n ≤ N
Establish: n, r, s := 0, 1, B
Guard: n ≠ N
vf: N - n

(n, r, s := n+1, U, U').P0
= { text substitution }
U = C.(n+1) ∧ U' = B^(n+2)
= { (2), algebra }
U = A * C.n + B^(n+1) ∧ U' = B * B^(n+1)
= { P0 }
U = A*r + s ∧ U' = B*s

n, r, s := 0, 1, B
;do n ≠ N →
	n, r, s := n+1, A*r + s, B*s
od
// O(N)
```
又是线性组合，写成矩阵（D 是矩阵变量，避免和常数 A、B 重名）：

$$
\begin{pmatrix}r\\ s\end{pmatrix} := \begin{pmatrix}A & 1\\ 0 & B\end{pmatrix}\begin{pmatrix}r\\ s\end{pmatrix}
\qquad
P0:\ \begin{pmatrix}A & 1\\ 0 & B\end{pmatrix}^N\begin{pmatrix}1\\ B\end{pmatrix} = D^n\begin{pmatrix}r\\ s\end{pmatrix}
$$

```
Establish: n, (r,s), D := N, (1,B), [[A,1],[0,B]]
Loop body:
	even.n → n, D := n div 2, D*D
	odd.n  → n, (r,s) := n-1, D*(r,s)

去掉矩阵之后的最终程序：
n, r, s, a, b, c, d := N, 1, B, A, 1, 0, B
;do n ≠ 0 →
	if even.n → n, a, b, c, d := n div 2, a*a+b*c, (a+d)*b, (a+d)*c, b*c+d*d
	[] odd.n → n, r, s := n-1, a*r + b*s, c*r + d*s
	fi
od
{ r = C.N }
// O(log N)
```

## Fibonacci like function with a constant term
```
(0) f.0 = 3
(1) f.1 = 5
(2) f.(n+2) = f.n + 4*f.(n+1) + 7 , 0 ≤ n

O(N) 版本（推导和 Fast Fibonacci 一模一样）：
P0: x = f.n ∧ y = f.(n+1)
n, x, y := 0, 3, 5
;do n ≠ N →
	n, x, y := n+1, y, x + 4*y + 7
od
```
问题是 +7 这个常数项不是线性组合，没法直接写成矩阵。办法是**把常数也变成一个变量**：
```
P2: z = 7

n, x, y, z := 0, 3, 5, 7
;do n ≠ N →
	n, x, y, z := n+1, y, x + 4*y + z, z
od
```
这样就是 3 个变量的线性组合了（和上学期 Recursion 里遇到常数就加一个 γ 当累加器是一个思路）：

$$
\begin{pmatrix}x\\ y\\ z\end{pmatrix} := \begin{pmatrix}0 & 1 & 0\\ 1 & 4 & 1\\ 0 & 0 & 1\end{pmatrix}\begin{pmatrix}x\\ y\\ z\end{pmatrix}
\qquad
P0:\ \begin{pmatrix}0 & 1 & 0\\ 1 & 4 & 1\\ 0 & 0 & 1\end{pmatrix}^N\begin{pmatrix}3\\ 5\\ 7\end{pmatrix} = A^n\begin{pmatrix}x\\ y\\ z\end{pmatrix}
$$

```
最终程序：
n, A, (x,y,z) := N, [[0,1,0],[1,4,1],[0,0,1]], (3,5,7)
;do n ≠ 0 →
	if even.n → n, A := n div 2, A*A
	[] odd.n → n, (x,y,z) := n-1, A*(x,y,z)
	fi
od
{ x = f.N }
// O(log N)。3x3 矩阵拆成 9 个变量太长了，PDF 里也没拆，写到矩阵形式就行
```

## Fibolucci
f 是 Fibonacci（f.0 = 0, f.1 = 1），N ≥ 1，求下面这个式子，并且**程序里不能出现 f**：
```
Post: r = 〈+ i : 0 ≤ i ≤ N : f.i * f.(N-i)〉

Post: r = C.n ∧ n = N
(3) C.n = 〈+ i : 0 ≤ i ≤ n : f.i * f.(n-i)〉 , 0 ≤ n ≤ N
(4) C.0 = 0                      // f.0 * f.0
(5) C.1 = 0                      // f.0 * f.1 + f.1 * f.0

C.(n+1)
= { (3) }
〈+ i : 0 ≤ i ≤ n+1 : f.i * f.((n+1)-i)〉
= { split off i = n+1 term }
〈+ i : 0 ≤ i ≤ n : f.i * f.((n+1)-i)〉 + f.(n+1) * f.0
= { (0) Zero*, Id+ }                                       // f.0 = 0，这一项没了
〈+ i : 0 ≤ i ≤ n : f.i * f.((n+1)-i)〉
= { split off i = n term }
〈+ i : 0 ≤ i ≤ n-1 : f.i * f.((n+1)-i)〉 + f.n * f.1
= { (1) Id* }
〈+ i : 0 ≤ i ≤ n-1 : f.i * f.((n+1)-i)〉 + f.n
= { i ≤ n-1，所以 (n+1)-i ≥ 2，可以用 (2) 展开 }           // 这就是为什么要先把 i = n 拆出来
〈+ i : 0 ≤ i ≤ n-1 : f.i * (f.((n-1)-i) + f.(n-i))〉 + f.n
= { */+, + associative }                                   // 分配律，拆成两个求和
〈+ i : 0 ≤ i ≤ n-1 : f.i * f.((n-1)-i)〉 + 〈+ i : 0 ≤ i ≤ n-1 : f.i * f.(n-i)〉 + f.n
= { 加上 f.n * f.(n-n) = 0，再反向 split off i = n }        // 凑出 C.n 的完整形式
〈+ i : 0 ≤ i ≤ n-1 : f.i * f.((n-1)-i)〉 + 〈+ i : 0 ≤ i ≤ n : f.i * f.(n-i)〉 + f.n
= { (3) }
C.(n-1) + C.n + f.n

(6) C.(n+1) = C.(n-1) + C.n + f.n , 1 ≤ n < N     // 要求 1 ≤ n，这样才能保证 n+1 ≥ 2
```
C.(n+1) 依赖 C.n 和 C.(n-1)，跟 Fibonacci 一样，用两个变量记：
```
P0: r = C.n ∧ s = C.(n-1)
P1: 1 ≤ n ≤ N
Establish: n, r, s := 1, 0, 0
Guard: n ≠ N
vf: N - n

(n, r, s := n+1, E, E').P0
= { text substitution }
E = C.(n+1) ∧ E' = C.n
= { (6) }
E = C.(n-1) + C.n + f.n ∧ E' = C.n
= { P0 }
E = s + r + f.n ∧ E' = r

n, r, s := 1, 0, 0
;do n ≠ N →
	n, r, s := n+1, s + r + f.n, r
od
```
程序里还有 f.n，题目不允许。再强化不变量：
```
P2: a = f.n ∧ b = f.(n-1)

(n, r, s, a, b := 1, 0, 0, E, E').P2
= { text substitution }
E = f.1 ∧ E' = f.0
= { (0) (1) }
E = 1 ∧ E' = 0

(n, r, s, a, b := n+1, s + r + f.n, r, E, E').P2
= { text substitution }
E = f.(n+1) ∧ E' = f.n
= { P1 让我们可以用 (2) }
E = f.(n-1) + f.n ∧ E' = f.n
= { P2 }
E = b + a ∧ E' = a

n, r, s, a, b := 1, 0, 0, 1, 0
;do n ≠ N →
	n, r, s, a, b := n+1, s + r + a, r, b + a, a
od
// O(N)，没有 f 了
```
PDF 说到这里"变量都是线性组合，换成矩阵就是 O(log N)，留给读者"。下面是补全的版本（已经和暴力解对拍过 N = 1..39）：

$$
\begin{pmatrix}r\\ s\\ a\\ b\end{pmatrix} := \begin{pmatrix}1 & 1 & 1 & 0\\ 1 & 0 & 0 & 0\\ 0 & 0 & 1 & 1\\ 0 & 0 & 1 & 0\end{pmatrix}\begin{pmatrix}r\\ s\\ a\\ b\end{pmatrix}
$$

循环从 n = 1 跑到 n = N，一共 N-1 次，初始向量是 (0, 0, 1, 0)，所以 tail invariant 是：

$$
P0:\ M^{N-1}\begin{pmatrix}0\\ 0\\ 1\\ 0\end{pmatrix} = A^n\begin{pmatrix}r\\ s\\ a\\ b\end{pmatrix}
\qquad M = \begin{pmatrix}1 & 1 & 1 & 0\\ 1 & 0 & 0 & 0\\ 0 & 0 & 1 & 1\\ 0 & 0 & 1 & 0\end{pmatrix}
$$

```
n, A, (r,s,a,b) := N-1, M, (0,0,1,0)       // N ≥ 1，所以 N-1 ≥ 0
;do n ≠ 0 →
	if even.n → n, A := n div 2, A*A
	[] odd.n → n, (r,s,a,b) := n-1, A*(r,s,a,b)
	fi
od
{ r = C.N }
// O(log N)
```

# Search by elimination
## Generic algorithm
给一个非空有限集合 W 和一个布尔函数 F，已知 W 里至少有一个元素满足 F，找出一个。
```
Pre: 〈∃ w : w ∈ W : F.w〉
Post: F.x

(0) P.V = 〈∃ v : v ∈ V : F.v〉 , V ⊆ W         // "V 里面还有答案"
于是 spec 可以写成
Pre: P.W
Post: P.{x}                                    // 只剩一个元素，且它是答案

Invariants
P0: P.V
P1: V ⊆ W
Establish: V := W
vf: #.V                                        // 集合的大小
Guard: #.V ≠ 1

框架：
V := W
;do #.V ≠ 1 →
	"Decrease #.V but keep the invariants true"
od
{ P0 ∧ P1 ∧ #.V = 1 }
;x := "V 里剩下的那个元素"
```
进入循环时 #.V ≠ 1 且 W 非空，所以 V 里至少有两个元素。每次挑两个不同的 a, b，扔掉其中一个：
```
V := W
;do #.V ≠ 1 →
	"Choose a, b ∈ V, a ≠ b"
	;if α → V := V\{a}
	[] β → V := V\{b}
	fi
od
;x := "V 里剩下的那个元素"
```
接下来推 α：我们需要的是"扔掉 a 之后答案还在"，也就是 P.V ⇒ P.(V\{a})
```
P.V ⇒ P.(V\{a})
= { split off a ∈ V }
P.(V\{a}) ∨ F.a ⇒ P.(V\{a})
= { [P ∨ Q ⇒ Q ≡ P ⇒ Q] }
F.a ⇒ P.(V\{a})
= { split off b ∈ V\{a} }
F.a ⇒ F.b ∨ P.(V\{a, b})
⇐ { [(P ⇒ Q) ⇒ (P ⇒ (Q ∨ R))] }
F.a ⇒ F.b
```
所以 α 取 **F.a ⇒ F.b**，对称地 β 取 **F.b ⇒ F.a**。

直观理解："如果 a 是答案，那 b 也是答案"，那扔掉 a 不会把答案全丢掉。

```
V := W
;do #.V ≠ 1 →
	"Choose a, b ∈ V, a ≠ b"
	;if F.a ⇒ F.b → V := V\{a}
	[] F.b ⇒ F.a → V := V\{b}
	fi
od
;x := "V 里剩下的那个元素"
```
这个就叫 **Searching by Elimination**。

> [!NOTE] split off 在集合上怎么用
> P.V = 〈∃ v : v ∈ V : F.v〉，∃ 其实就是 ∨ 的 quantified form。因为 a ∈ V，可以把 v = a 这一项拆出来：
> 〈∃ v : v ∈ V\{a} : F.v〉 ∨ F.a = P.(V\{a}) ∨ F.a
> 和上学期 split off a term 是一回事，只不过 range 从区间变成了集合。

## Symmetric Linear Search
很多时候集合是一个有序区间 W = [M..N]（M ≤ N），那就用两个指针 a, b 表示 V = [a..b]，每次扔掉一头：
```
a, b := M, N
;do a ≠ b →
	if F.a ⇒ F.b → a := a+1
	[] F.b ⇒ F.a → b := b-1
	fi
od
;x := a
```
这个叫 **Symmetric Linear Search**（从两头往中间夹）。

> [!NOTE] 具体题目里怎么推 guard
> F.a ⇒ F.b 本身通常不好算，所以要找一个**更强**（⇐）但好算的条件代替它。常用的套路：
> 1. **[¬P ⇒ (P ⇒ Q)]**：只要能证明 a 肯定不是答案（¬F.a），就可以扔掉 a。Celebrity 用的就是这个
> 2. **传递性**：比如 F 是"x 是最大值"，那 g.a ≤ g.b 就够了
> 3. **展开定义 + 代数**：Starting pit 用的就是这个
>
> 注意：换成更强的条件之后，要自己检查两个 guard 并起来还能覆盖所有情况（上学期 if..fi 的规则 P ⇒ B0 ∨ B1），不然 if 会 abort。
> 原始的 (F.a ⇒ F.b) ∨ (F.b ⇒ F.a) 永远为真，但换掉之后就要重新检查了。下面几个例子都是满足的。

## The Celebrity problem
N 个人里面一定有一个名人。名人的定义：他**不认识**其他任何人，但其他所有人**都认识**他。找出这个名人。

用二维布尔数组 R[1..N, 1..N] 表示，R.i.j ≡ "i 认识 j"。
```
(0) F.x ≡ 〈∀ i : i ≠ x : R.i.x ∧ ¬R.x.i〉       // 所有人都认识 x，且 x 不认识任何人
Pre: 〈∃ k : 1 ≤ k ≤ N : F.k〉
Post: F.x

F.a ⇒ F.b
⇐ { [¬P ⇒ (P ⇒ Q)] }
¬F.a
= { (0) }
¬〈∀ i : i ≠ a : R.i.a ∧ ¬R.a.i〉
= { generalized De Morgan }
〈∃ i : i ≠ a : ¬R.i.a ∨ R.a.i〉
⇐ { a ≠ b，取 i = b }
¬R.b.a ∨ R.a.b              // b 不认识 a，或者 a 认识 b → a 肯定不是名人

对称地 F.b ⇒ F.a ⇐ ¬R.a.b ∨ R.b.a

最终程序：
a, b := 1, N
;do a ≠ b →
	if ¬R.b.a ∨ R.a.b → a := a+1
	[] ¬R.a.b ∨ R.b.a → b := b-1
	fi
od
;x := a
// O(N)，两个 guard 并起来是永真式
```

## The location of the maximum value
给定 g[M..N] of int（M ≤ N），找最大值的位置。
```
(0) F.x ≡ 〈∀ i :: g.i ≤ g.x〉
Pre: 〈∃ k : M ≤ k ≤ N : F.k〉        // 最大值一定存在
Post: F.x

F.a ⇒ F.b
= { definition of F twice }
〈∀ i :: g.i ≤ g.a〉 ⇒ 〈∀ i :: g.i ≤ g.b〉
⇐ { ≤ is transitive }
g.a ≤ g.b

对称地 F.b ⇒ F.a ⇐ g.b ≤ g.a

最终程序：
a, b := M, N
;do a ≠ b →
	if g.a ≤ g.b → a := a+1
	[] g.b ≤ g.a → b := b-1
	fi
od
;x := a
```

## The starting pit problem
环形赛道上有 N 个加油站，编号 1..N。在 i 站能加 p.i 升油，从 i 开到下一个站需要 q.i 升油。找一个站，从这里**空油箱**出发能跑完一整圈。

为了保证这样的站一定存在，题目给了：
```
(0) 〈+ i : 1 ≤ i ≤ N : p.i〉 = 〈+ i : 1 ≤ i ≤ N : q.i〉      // 总油量 = 总消耗
```
定义 D.i.j 为从 i 开到 j 的油量盈余：
```
(1) D.i.j = 〈+ k : i ≤ k < j : p.k - q.k〉
(2)  D.i.j = D.(i+1).j + (p.i - q.i)
(3)  D.i.j = D.i.(j-1) + (p.(j-1) - q.(j-1))
(2') D.(i+1).j = D.i.j - (p.i - q.i)                 // 后面用的是这两个形式
(3') D.i.(j-1) = D.i.j - (p.(j-1) - q.(j-1))
(4) D.i.k = D.i.j + D.j.k
(5) D.i.i = 0
(6) D.i.j + D.j.i = 0
// 赛道是环形的，比如 D.2.1 = D.2.N + D.N.1，PDF 为了不把记号搞复杂就没有引入取模
```
套 symmetric linear search：
```
(7) F.x ≡ 〈∀ i :: 0 ≤ D.x.i〉          // 从 x 出发，到任何一站油量都不会是负的
Pre: 〈∃ k : 1 ≤ k ≤ N : F.k〉
Post: F.x

F.a ⇒ F.b
= { definition of F }
〈∀ i :: 0 ≤ D.a.i〉 ⇒ 〈∀ i :: 0 ≤ D.b.i〉
= { (4) }
〈∀ i :: 0 ≤ D.a.b + D.b.i〉 ⇒ 〈∀ i :: 0 ≤ D.b.i〉
⇐ { arithmetic }
D.a.b ≤ 0

对称地 (F.b ⇒ F.a) ⇐ D.b.a ≤ 0
由 (6) D.b.a = -D.a.b，所以 (F.b ⇒ F.a) ⇐ 0 ≤ D.a.b
```
直观理解：D.a.b ≤ 0 说明从 a 开到 b 油不够（或者刚好用完）。如果 a 是答案，那到 b 的时候油箱是 D.a.b ≥ 0，两个一合就是刚好空箱到达 b——这等价于从 b 空箱出发，所以 b 也是答案。扔掉 a 是安全的。

```
第一版程序：
a, b := 1, N
;do a ≠ b → { 1 ≤ a < b ≤ N }
	if D.a.b ≤ 0 → a := a+1
	[] 0 ≤ D.a.b → b := b-1
	fi
od
;x := a
```
每次算 D.a.b 太贵了，所以又是**强化不变量**：
```
P2: d = D.a.b

Establish：需要 d = D.1.N，由 (6) D.1.N = -D.N.1 = -(p.N - q.N) = q.N - p.N
所以 a, b, d := 1, N, q.N - p.N

(a, d := a+1, E).P2
= { text sub. }
E = D.(a+1).b
= { (2') }
E = D.a.b - (p.a - q.a)
= { P2 }
E = d - (p.a - q.a)

(b, d := b-1, E).P2
= { text sub. }
E = D.a.(b-1)
= { (3') }
E = D.a.b - (p.(b-1) - q.(b-1))
= { P2 }
E = d - (p.(b-1) - q.(b-1))

最终程序：
a, b, d := 1, N, q.N - p.N
;do a ≠ b → { 1 ≤ a < b ≤ N }
	if d ≤ 0 → a, d := a+1, d - (p.a - q.a)
	[] 0 ≤ d → b, d := b-1, d - (p.(b-1) - q.(b-1))
	fi
od
;x := a
// O(N)
```
